# Health History

A simple place to store and collect your health reports online.
Upload photos or PDFs of lab reports, prescriptions, doctor notes and bills — **in any order** — and the AI reads everything written on them and builds your health timeline.

Green, white & black. Classic, minimal, works on mobile and desktop from one page.

## Pages

| Page | What it does |
|---|---|
| **Home** | Upload box — *Take photo* (opens the camera on phones) or *Gallery / Files* (images & PDFs, drag-and-drop on desktop). Scan with AI & save. |
| **History** | Timeline sorted by date. Each record shows: **Health Report \| Made by whom**, *what the report says* in simple words (with a test-result table, high/low flagged), **Consulted doctor \| Clinic/Hospital**, *what the doctor suggested* and *tablets given*, a **TL;DR** line, and **Sources** — tap to see the original report photos. Search across everything. |
| **Profile** | Personal details (name, DOB, blood group, allergies, conditions, emergency contact), stats, and a **Complete health report** of the patient generated by AI from all records — printable / save as PDF. Export / import backup, delete all. |

Mobile: bottom pill nav (Home | History) and the profile initial at top-right. Desktop: top nav.

## How it works

```
Browser (index.html + app.js)                Vercel serverless
  ├─ compress photos (≤1800px JPEG)          /api/scan    → Claude reads images/PDFs → structured records (JSON)
  ├─ POST /api/scan  ───────────────────▶    /api/summary → Claude combines all records → complete health report
  └─ save records + files in IndexedDB
     (stays on the user's device)
```

- No build step — plain HTML/CSS/JS.
- **Login with email + password** (Supabase Auth). Records are saved to the user's account (Postgres) and report files to a private storage bucket — Row Level Security means each user sees only their own data, on any device.
- AI endpoints only work for logged-in users. Files go to the AI only during a scan; if a scan fails the files are still saved and can be re-scanned.
- Multiple uploads from different visits are split into separate records and dated automatically.

## Deploy (Vercel)

1. Import this repo in Vercel (Framework preset: **Other**, no build command).
2. Supabase: run `supabase/schema.sql` in the SQL editor, put the project URL + publishable key in `config.js`.
3. Vercel environment variables: `ANTHROPIC_API_KEY`, `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` (optional `ANTHROPIC_MODEL`, default `claude-sonnet-5-5`).
4. Supabase → Authentication → URL Configuration: set Site URL to your Vercel URL (for confirmation & password-reset emails).
5. Deploy.

Local: `npm i -g vercel && vercel dev` (needs `.env` — see `.env.example`).
